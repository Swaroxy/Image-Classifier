# Image-Classifier
This project is a Cats vs Dogs image classification system built with TensorFlow and Keras. It covers a complete computer vision workflow, from dataset preparation, balanced sampling, and stratified train/validation/test splitting to image preprocessing and reproducible model training. The project implements a baseline CNN, an improved CNN with data augmentation, dropout, EarlyStopping, ModelCheckpoint, and learning-rate reduction, as well as EfficientNetB0 using transfer learning and fine-tuning. Model performance is evaluated using accuracy, loss, confusion matrices, classification reports, learning curves, and sample predictions. Overall, the project demonstrates key practical concepts in image classification, including CNNs, data augmentation, regularization, overfitting control, callbacks, transfer learning, fine-tuning, and model evaluation.
